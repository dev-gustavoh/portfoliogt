01 — Sobre

Gustavo Amaral é Bacharel em Ciências da Computação e atua como desenvolvedor no Senado Federal — onde constrói e mantém sistemas institucionais usando Oracle APEX, PL/SQL e JavaScript em ambiente de alta criticidade.

Trabalha na interseção entre engenharia de software e produto — do back ao front, de scripts Python a aplicações Next.js com arquitetura modular e moderna.

Paralelamente ao ambiente corporativo, desenvolve projetos pessoais que exploram gamificação, mobilidade urbana e sistemas web completos. Seu projeto mais ambicioso — LifeQuest — combina Next.js 14, PostgreSQL, Prisma e integração com OpenAI em uma plataforma SaaS de desenvolvimento pessoal.

Interesses técnicos atuais: arquitetura de software escalável, integração de LLMs em produto, desenvolvimento mobile com React Native e sistemas de dados relacionais.
